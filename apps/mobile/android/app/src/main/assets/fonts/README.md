# Nordwand Mono

Unmodified upstream fonts from [Nordwand Mono 1.4.0](https://github.com/tywr/Nordwand-Mono/releases/tag/1.4.0), by Tanguy VIVIER. Distributed under the SIL Open Font License 1.1; see [OFL.txt](OFL.txt).

TTF files in `res/font` are extracted from `NordwandMono-TTF.zip`; WOFF2 files here are extracted from `NordwandMono-WOFF2.zip`. Assets are bundled locally; no runtime font downloads. Android API 28+ selects actual regular/medium/semibold/bold and italic variants. On Android API 24–27, React Native maps intermediate weights to regular or bold; the family remains Nordwand Mono. Web surfaces use regular/bold and italic variants.
